# Voltical Art Director

This is the default behavior for open-ended improvement, “more Apple-like,” or
directional reference requests. Use the reference to understand relationships;
do not turn it into a literal template unless the user requests strict matching.

## Design hierarchy

Choose one hero per card:

- a result or number when the value is the product promise;
- a short benefit phrase when interpretation matters more than magnitude;
- a product image when material, compactness, or physical interaction is the
  message.

Arrange supporting roles in descending importance: eyebrow/context, hero,
meaning, qualifier, then artwork or secondary evidence. Remove competition
before adding emphasis. Preserve deliberate negative space.

Use optical rather than purely mathematical centring when a glyph, icon, crop,
or asymmetric text block appears off-centre. Keep sibling card geometry and role
hierarchy coherent without forcing all content into identical coordinates.

## Voltical voice and visual choices

- Preserve verified product facts, quantities, units, and qualifiers.
- Prefer concise, direct copy that explains the benefit without inflated or
  unsupported claims.
- Use existing Voltical assets and tokens first. The theme's `--sans` is the
  normal brand text family; a system/SF-like stack is a deliberate reference
  choice, not an automatic “Apple” requirement.
- Use white cards, restrained supporting colour, clipped imagery, and clean
  spacing when they serve clarity. These are design decisions, not branding
  proof.
- A gradient must improve hierarchy or communicate a product idea. A solid ink
  value is often the more disciplined choice.

## Responsive composition

Design mobile and desktop around the same message but allow different card
proportions, type scales, crop windows, padding, and grid structures. Check the
actual final cascade before proposing dimensions. Never assume a percentage
scale produces the correct other viewport.

For transparent artwork, measure its alpha/non-background bounds and size the
visible object. Preserve the intended focal point and ensure crop changes do not
expose empty canvas or hide required product detail.

## Scope of creative change

Implement a narrowly specified request without adding a redesign ceremony. For
a composition or copy redesign, state the proposal before editing:

- chosen hero and why;
- support roles and reading order;
- mobile and desktop composition;
- copy/assets that will change;
- explicit elements and sibling cards that will not change.

Do not broaden one card into a section-wide restyle unless the user accepts that
scope.
